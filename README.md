# PDF Tools Desktop — instaladores

Aquí se publican los instaladores de **PDF Tools Desktop**. La app instalada revisa este repositorio y se actualiza sola cuando hay una versión nueva.

Para instalarla por primera vez, descarga el instalador de la [última versión](../../releases/latest):

- **Windows:** `PDF.Tools.Desktop.Setup.<versión>.exe` (o `PDF.Tools.Desktop.<versión>.exe`, versión portátil sin instalación).
- **macOS (Apple Silicon):** `PDF.Tools.Desktop-<versión>-arm64.dmg`.

La app necesita activarse con un código de activación.
